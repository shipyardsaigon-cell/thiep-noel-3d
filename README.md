# 🎄 Thiệp Giáng Sinh 3D

Thiệp Giáng sinh 3D trong series **Code cùng Shipyard** (học lập trình web cho học sinh cấp 2).

👉 Mở thiệp: https://shipyardsaigon-cell.github.io/thiep-noel-3d/

## Có gì trong thiệp
- Cảnh 3D dựng bằng [three.js](https://threejs.org): cây thông nhiều tầng, đèn nháy xoắn ốc, quả châu bóng loáng, ngôi sao phát sáng (bloom), người tuyết, hộp quà, rừng thông, mặt trăng, cực quang và tuyết rơi
- Kéo để xoay cảnh, bấm "Mở quà" hoặc chạm vào hộp quà đỏ: nắp hộp bật ra, pháo giấy, pháo hoa, nhạc chuông "Jingle Bells"
- Hoạt hình ông già Noel bằng [Lottie](https://airbnb.io/lottie/) (lottie-web)
- Tự tạo thiệp có tên người nhận để gửi đi

## Nguồn
- three.js (MIT), lottie-web (MIT), tải từ CDN jsDelivr và cdnjs
- 3 hoạt hình Lottie miễn phí từ LottieFiles, dùng theo Lottie Simple License: ông già Noel vẫy tay "Merry Christmas", ông già Noel chui ra từ hộp quà, xe trượt tuần lộc
- Nhạc "Jingle Bells" (bài hát thuộc phạm vi công cộng) phát bằng Web Audio API
